1ระบบนี้คืออะไร

1.1 ขอบเขตของระบบ

ระบบนี้เป็น ระบบแสดงผลการศึกษา (Research Result Visualization) ทำหน้าที่นำผลการวิเคราะห์และผลการพยากรณ์ที่คำนวณเสร็จแล้วมาแสดงบนแผนที่และกราฟ เพื่อให้อ่านและเปรียบเทียบได้สะดวก

ระบบนี้ทำ
  • แสดงอนุกรมเวลา SLA และตัวแปรอุตุนิยมวิทยาของแต่ละสถานี
  • แสดงค่าจริงเทียบค่าพยากรณ์ของทั้งสามแบบจำลอง
  • เปรียบเทียบประสิทธิภาพและชี้แบบจำลองที่ดีที่สุดของแต่ละสถานี
  • แสดงความสำคัญของตัวแปรใน Random Forest
  • เรียบเรียงรายงานสรุปให้อัตโนมัติจากไฟล์ข้อมูล
ระบบนี้ไม่ทำ
  • ไม่ใช่ระบบ real-time ไม่ดึงข้อมูลสด ไม่มีการเตือนภัย
  • ไม่ฝึกแบบจำลองใหม่และไม่คำนวณค่าพยากรณ์ใหม่
  • ไม่แก้ค่าตัวชี้วัดหรือผลทางวิทยาศาสตร์ใด ๆ
  • ไม่เดาค่าที่ไม่มีในไฟล์ — จะแสดง N/A ตามความเป็นจริง
  • ไม่มีฐานข้อมูลและไม่มี backend
สิ่งที่ต้องเข้าใจก่อนใช้ตัวเลขทุกค่าบนหน้าเว็บถูกคำนวณไว้ล่วงหน้าในโน้ตบุ๊กวิจัย SLA_predict_SARIMA_RF_LSTM.ipynb แล้วแปลงเป็นไฟล์ CSV/GeoJSON/JSON หน้าเว็บเพียง อ่านมาแสดง การเปิดหน้าเว็บซ้ำหรือเปลี่ยนตัวเลือกใด ๆ จึงไม่ทำให้ผลเปลี่ยน

2.2 เปิดในเครื่อง

หน้าเว็บอ่านไฟล์ในโฟลเดอร์ data/ ด้วยคำสั่ง fetch() ซึ่งเบราว์เซอร์จะปฏิเสธถ้าเปิดไฟล์ตรง ๆ ด้วย file:// ต้องเปิดผ่านเว็บเซิร์ฟเวอร์เท่านั้น

  1. เปิด Command Prompt หรือ PowerShell
  2. เข้าไปที่โฟลเดอร์ของเว็บ — ถ้าใช้ repo งานวิจัยให้พิมพ์ cd webapp ถ้าใช้ repo เฉพาะเว็บอยู่ที่ root แล้วไม่ต้อง cd
  3. สั่ง python -m http.server 8000
  4. เปิดเบราว์เซอร์ไปที่ http://localhost:8000
  5. กด Ctrl+C ที่หน้าต่างคำสั่งเมื่อต้องการปิดเซิร์ฟเวอร์
อาการเมื่อเปิดผิดวิธีถ้าเปิดด้วย file:// จะเห็นข้อความ “โหลดข้อมูลไม่สำเร็จ” พร้อมคำแนะนำบนหน้าเว็บ ไม่ใช่หน้าขาว

3.2 โหมดสว่าง/มืด

ปุ่มวงกลมครึ่งดำครึ่งขาวที่มุมขวาของแถบบนใช้สลับโหมดสี ระบบจำค่าที่เลือกไว้ ในเครื่องผู้ใช้ ครั้งต่อไปจะเปิดด้วยโหมดเดิม ถ้าไม่เคยเลือกจะใช้ตามการตั้งค่าของ ระบบปฏิบัติการ สีของกราฟถูกปรับให้อ่านได้ทั้งสองโหมด

3.3 ตัวเลือกสถานี

สถานีที่เลือกไว้ ติดตามไปทุกหน้า เลือกที่หน้าใดก็ได้ผลเหมือนกัน เปลี่ยนได้ 3 ทาง

  1. เลือกจาก ช่องเลือกสถานีบนแถบบน ซึ่งใช้ได้จากทุกหน้า
  2. คลิกหมุดสถานีบนแผนที่ในหน้าภาพรวม
  3. คลิกรายการสถานีในกล่อง “สถานีศึกษา” ข้างแผนที่
  4. เลือกจากช่องเลือกสถานีบนแถบตัวกรองของแต่ละหน้า

หน้ารายงานอัตโนมัติสรุปทั้ง 4 สถานีพร้อมกัน จึงไม่มีช่องเลือกสถานี

3.4 สีและเส้นประจำชุดข้อมูล

4หน้าที่ 1 — ภาพรวม (Overview)

ใช้ดูว่าพื้นที่ศึกษาอยู่ที่ใด แต่ละสถานีมีสถานะล่าสุดอย่างไร และแบบจำลองใดทำงานได้ดีที่สุดในแต่ละสถานี

4.1 การ์ดตัวเลขหลัก

แถวบนสุดของหน้าเป็นการ์ดตัวเลข 4 ใบของ สถานีที่เลือกอยู่ แต่ละใบใช้สีต่างกันเพื่อให้จำแยกได้ และมีเส้นกราฟจิ๋วอยู่ด้านล่าง เส้นนี้บอกเพียง รูปร่าง ของอนุกรม ไม่ได้ให้อ่านค่า จึงไม่มีแกนกำกับ

ตารางที่ 4.1 การ์ดตัวเลขหลักบนหน้าภาพรวม
การ์ดค่าที่แสดงเส้นกราฟจิ๋วคืออะไร
SLA ล่าสุดในชุดข้อมูลค่า SLA เดือนสุดท้ายที่มีข้อมูล (เดือน 2024-12) ไม่ใช่ค่าปัจจุบันค่า SLA 24 เดือนสุดท้าย
แนวโน้มเชิงเส้นความชันของเส้นถดถอยเชิงเส้น หน่วยมิลลิเมตรต่อปีอนุกรม SLA เต็มช่วง 1993-01 – 2024-12
แบบจำลองที่ดีที่สุดแบบจำลองที่ RMSE ต่ำสุดบนชุด Test พร้อมค่า RMSE, R² และ MAEค่าพยากรณ์ของแบบจำลองนั้นบนชุด Test

ตารางที่ 4.3 การ์ดสรุปรายสถานี

4.4 ตารางสรุปรายสถานีและกราฟแท่งสองรูป

ด้านล่างของหน้ามีตารางรวมทุกสถานีไว้ในที่เดียว ต่อด้วยกราฟแท่งสองรูป รูปซ้ายเทียบ RMSE ของแบบจำลองที่ดีที่สุดในแต่ละสถานี (ยิ่งแท่งสั้นยิ่งแม่น) รูปขวาเทียบแนวโน้ม SLA ของแต่ละสถานีเป็นมิลลิเมตรต่อปี

4.5 สัดส่วนความสำคัญของตัวแปร และความแม่นของแบบจำลอง

สองการ์ดท้ายหน้าสรุปผลของแบบจำลองในมุมที่อ่านเร็ว

ตารางที่ 4.4 การ์ดสรุปผลแบบจำลองบนหน้าภาพรวม
การ์ดอ่านอย่างไร
สัดส่วนความสำคัญของตัวแปร (กราฟวงกลม)แบ่งค่า MDI ของ Random Forest ตามกลุ่มตัวแปร เฉลี่ยข้ามทุกสถานี ผลรวมของแต่ละสถานีเท่ากับ 1 จึงรวมกันได้ 100% สีในกราฟนี้เป็นสีของหน้าเว็บสำหรับแยกกลุ่ม ไม่ใช่สีประจำแบบจำลอง
ความแม่นของแบบจำลอง (แถบแนวนอน)ค่า R² บนชุด Test ของสถานีที่เลือก แถบยาวเต็มคือ R² = 1 ซึ่งหมายถึงทำนายตรงทุกจุด ใต้แถบกำกับ RMSE และ MAE ไว้ และแบบจำลองที่ดีที่สุดมีป้าย “ดีที่สุด” แถบใช้สีประจำแบบจำลองตามตารางที่ 3.3
แถบนี้ไม่ใช่ความคืบหน้าไปสู่เป้าหมายR² เป็นสัดส่วนระหว่าง 0 ถึง 1 อยู่แล้ว จึงแสดงเป็นแถบได้ตรง ๆ งานวิจัยไม่ได้ตั้งค่าเป้าหมายของตัวชี้วัดไว้ ระบบจึงไม่แสดงเส้นเป้าหมายใด ๆ
ค่าจริงของระบบขณะสร้างคู่มือแบบจำลองที่ดีที่สุดของทั้ง 4 สถานีคือ SARIMA โดยมี RMSE ระหว่าง 0.0403 ถึง 0.0485 เมตร และแนวโน้ม SLA เป็นบวกทุกสถานี ดูค่าทั้งหมดในภาคผนวก ก และ ข

5หน้าที่ 2 — การวิเคราะห์ SLA

ใช้ดูพฤติกรรมของระดับน้ำทะเลในอดีตของสถานีที่เลือก ทั้งค่าสถิติภาพรวม แนวโน้มระยะยาว และรูปแบบตามฤดูกาล

5.1 แถบตัวกรอง

มีสองส่วน คือช่องเลือกสถานี และปุ่มเปิด/ปิดแถบสีบอกช่วง Train / Validation / Test บนกราฟ การปิดแถบสีช่วยให้ดูเส้นข้อมูลได้ชัดขึ้น การเปิดช่วยให้เห็นว่าช่วงใดถูกใช้ฝึกและช่วงใดถูกใช้ทดสอบ

5.3 กราฟอนุกรมเวลา SLA

เส้นสีน้ำเงินคือค่า SLA รายเดือน เส้นตรงทับอยู่คือเส้นแนวโน้มเชิงเส้น เส้นประแนวนอนที่ระดับศูนย์เป็นเส้นอ้างอิง ไม่ใช่ข้อมูล ค่าเป็นบวกหมายถึงระดับน้ำสูงกว่าค่าอ้างอิง ค่าเป็นลบหมายถึงต่ำกว่า

ใต้กราฟมีหัวข้อพับเก็บชื่อ “ดูข้อมูลเป็นตาราง” กดเพื่อดูค่ารายเดือนทั้งหมด ของสถานีที่เลือกเป็นตัวเลข

5.4 ค่าเฉลี่ยรายเดือนตามปฏิทิน

กราฟสุดท้ายของหน้าคือรูปแบบฤดูกาล คำนวณโดยเฉลี่ยค่าของเดือนเดียวกัน ข้ามทุกปีในช่วงข้อมูล แถบรอบเส้นคือช่วง ±1 ส่วนเบี่ยงเบนมาตรฐาน กราฟนี้บอกว่าเดือนใดระดับน้ำมักสูงและเดือนใดมักต่ำ

ค่าจริงของระบบขณะสร้างคู่มือทุกสถานีมีค่าเฉลี่ยรายเดือนสูงสุดในเดือนธันวาคม ส่วนเดือนต่ำสุดเป็นมิถุนายน ยกเว้นสถานี Wat Khun Samut Chin ที่ต่ำสุดในเดือนสิงหาคม ดูค่าทั้งหมดในภาคผนวก ง

6.2 การเลือกดู

แถบตัวกรองมีช่องเลือกสถานี และปุ่มเลือกตัวแปรที่ต้องการแสดง กดปุ่มตัวแปรเพื่อเปิดหรือปิดแผงกราฟของตัวแปรนั้น เลือกได้หลายตัวพร้อมกัน

ตัวแปรแต่ละตัวมีแผงกราฟของตัวเอง ไม่นำมาไว้บนแกนเดียวกัน เพราะหน่วยต่างกันมาก การวางองศาเซลเซียสกับเฮกโตปาสคาลบนแกนเดียวกัน จะทำให้อ่านค่าผิด

6.3 การแปลงหน่วย

ไฟล์ต้นทางของ ERA5 เก็บอุณหภูมิเป็นเคลวินและความกดอากาศเป็นปาสคาล ระบบแปลงเป็นองศาเซลเซียสและเฮกโตปาสคาลตามลำดับ โดย อ่านหน่วยจาก metadata ของไฟล์ ไม่ใช้ค่าคงที่แบบเดา ส่วน u10 และ v10 คงหน่วยเดิมเป็นเมตรต่อวินาที

ทำไมไม่ทำเป็นชั้นข้อมูลบนแผนที่ตัวแปร ERA5 ถูกเฉลี่ยเป็นค่าเดียวต่อสถานีต่อเดือนแล้วก่อนเข้าแบบจำลอง การแสดงเป็นอนุกรมเวลาจึงตรงกับสิ่งที่แบบจำลองใช้จริง ต่างจากการแสดงเป็นภาพ raster ซึ่งเป็นข้อมูลก่อนการเฉลี่ย

7หน้าที่ 4 — ผลแบบจำลองและการพยากรณ์

หน้าหลักของการเปรียบเทียบแบบจำลอง แสดงว่าแต่ละแบบจำลอง พยากรณ์ได้ใกล้ค่าจริงเพียงใดบนชุดทดสอบ และตัวแปรใดมีบทบาทมากใน Random Forest

7.1 แถบตัวกรอง

เลือกสถานีได้จากช่องเลือก และเลือกได้ว่าจะให้กราฟแสดงแบบจำลองใดบ้าง ด้วยปุ่มชื่อแบบจำลอง การปิดบางแบบจำลองช่วยให้เทียบสองตัวได้ชัดขึ้น ทั้งนี้ ตารางตัวชี้วัดแสดงครบทุกแบบจำลองเสมอ ไม่ขึ้นกับปุ่มนี้

7.2 ตารางเปรียบเทียบประสิทธิภาพ

ตารางแสดงค่า MSE, MAE, RMSE และ R² ของทั้ง 3 แบบจำลอง ทุกสถานี แถวที่ถูกไฮไลต์คือแบบจำลองที่ดีที่สุดของสถานีนั้น ซึ่งตัดสินด้วย RMSE ต่ำสุด ตามตัวชี้วัดหลักของงานวิจัย

7.3 กราฟค่าจริงเทียบค่าพยากรณ์

เส้นทึบหนาสีดำคือค่าจริง เส้นลายอื่นคือค่าพยากรณ์ของแต่ละแบบจำลอง ครอบคลุมชุด Test เดือน 2020-01 ถึง 2024-12 รวม 60 เดือน เส้นที่แนบไปกับเส้นค่าจริงมากที่สุดคือแบบจำลองที่แม่นที่สุดในสายตา ส่วนการตัดสินเชิงตัวเลขให้ดูที่ตาราง

ตัวชี้วัดความหมายทิศทางที่ดีหน่วย
RMSE
Root Mean Squared Error		รากที่สองของค่าเฉลี่ยกำลังสองของความคลาดเคลื่อน ให้น้ำหนักกับความคลาดเคลื่อนก้อนใหญ่มากยิ่งต่ำยิ่งดีเมตร
MAE
Mean Absolute Error		ค่าเฉลี่ยของขนาดความคลาดเคลื่อน อ่านง่ายกว่าเพราะเป็นหน่วยเดียวกับข้อมูลยิ่งต่ำยิ่งดีเมตร
MSE
Mean Squared Error		ค่าเฉลี่ยกำลังสองของความคลาดเคลื่อน เป็นค่าก่อนถอดรากของ RMSEยิ่งต่ำยิ่งดีตารางเมตร
R²
Coefficient of Determination		สัดส่วนความแปรปรวนของข้อมูลที่แบบจำลองอธิบายได้ ค่า 1 คือทำนายตรงทุกจุดยิ่งสูงยิ่งดีไม่มีหน่วย

งานวิจัยกำหนดให้ RMSE (m) เป็นตัวชี้วัดหลัก การตัดสินว่าแบบจำลองใดดีที่สุดในระบบนี้จึงใช้ RMSE ต่ำสุดเสมอ ไม่ได้ใช้ R² หรือ MAE เพื่อให้เกณฑ์คงที่ตรงกันทุกที่

9.2 แนวโน้มเป็นสถิติเชิงพรรณนา

อ่านให้ถูกต้องแนวโน้มเชิงเส้นคำนวณจากอนุกรม SLA ที่แสดงบนกราฟด้วย np.polyfit(deg=1) ซึ่งเป็นวิธีเดียวกับ detrend_linear() ในโน้ตบุ๊ก เป็นสถิติเชิงพรรณนาของข้อมูล ไม่ใช่ผลลัพธ์ของแบบจำลอง

กล่าวคือค่ามิลลิเมตรต่อปีที่แสดงเป็นการสรุปลักษณะของข้อมูลที่เห็นบนกราฟ ไม่ใช่ผลลัพธ์ของ SARIMA, Random Forest หรือ LSTM และไม่ควรนำไปอ้างเป็นอัตราการเพิ่มของระดับน้ำทะเลในอนาคต

9.3 ทำไม Forecast เป็น N/A

งานวิจัยออกแบบให้พยากรณ์แบบ 1-step-ahead คือใช้ข้อมูลถึงเดือนหนึ่ง เพื่อทำนายเดือนถัดไป แล้ววัดผลบนชุด Test (2020-01 ถึง 2024-12) ไม่ได้ผลิตค่าพยากรณ์ของเดือนที่ยังไม่มีข้อมูลจริง

ระบบจึงแสดง N/A ตามความเป็นจริง ไม่สร้างค่าพยากรณ์ขึ้นเองในหน้าเว็บ ถ้าภายหลังงานวิจัยผลิตค่าพยากรณ์อนาคตออกมา ให้เติมแถวลงไฟล์ forecast.csv ตามหัวตาราง station, date, model, forecast_m, lower_m, upper_m ระบบจะวาดเส้น Forecast และเปลี่ยนข้อความจาก N/A ให้เองโดยไม่ต้องแก้โค้ด

9.4 ความสำคัญของตัวแปรอ่านอย่างไร

ค่าความสำคัญบอกว่า แบบจำลองใช้ตัวแปรใดในการทำนาย ไม่ใช่ข้อสรุปว่าตัวแปรนั้นเป็นสาเหตุทางกายภาพของการเปลี่ยนแปลงระดับน้ำ ความสัมพันธ์ทางสถิติกับความเป็นเหตุเป็นผลเป็นเรื่องต่างกัน

ควรดูทั้งสองมาตรวัดประกอบกัน ตัวแปรที่สำคัญจริงมักติดอันดับสูงทั้งสองแบบ และติดอันดับสูงในหลายสถานี ซึ่งหน้ารายงานสรุปให้แล้วในคอลัมน์ “ติด 3 อันดับแรก”

  1. commit การแก้ไขลง branch main ของ repo งานวิจัยให้เรียบร้อย
  2. git push origin main — repo งานวิจัยจะ deploy ตัวเองผ่าน Actions
  3. git subtree push --prefix=webapp webapp-repo main — ยกโฟลเดอร์ webapp/ ขึ้นเป็น root ของ repo เฉพาะเว็บ

ถ้ายังไม่เคยผูก remote ให้สั่งครั้งเดียวว่า
git remote add webapp-repo https://github.com/Jariya-aum/Demo_SLA_Web_app.git

คำสั่ง subtree อ่านจาก commit ไม่ได้อ่านจากไฟล์ในเครื่อง จึงต้อง commit ก่อนเสมอ ไม่เช่นนั้นจะไม่เห็นการเปลี่ยนแปลง
